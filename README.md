# Advanced Car Dealership App

## Description 

This is a car dealership management application that allows users to search and manage vehicle inventory across multiple dealerships. Users can filter vehicles by price, make, model, year, color, mileage, and type, as well as add and remove vehicles from inventory.
With the new additions, the app now supports sales and lease contracts. When a client is interested in a vehicle, staff can generate either a sales contract or a lease contract, collecting customer information and finance preferences in the process.  All contracts are saved to a persistent file and the vehicle is automatically removed from inventory once a contract is created.

## User Stories



- As a Sales Manager, I would like to be able to sales contract, so that if customers want to purchase a vehicle I can detail all the relevant information with them before purchase
- As a Sales Manager, I would like to be able to print a Lease Contract, so that I can give customers information detailing the terms in the case that they want to lease, rather than purchase.
- As a Sales Manager I would like to have my contracts saved to a file, so that I can have updated inventory saved
